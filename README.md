# INZENITH_EVENTS

หน้าเว็บแนะนำระบบลงทะเบียนและเช็กอินงานอีเวนต์ของ IN ZENITH

- `index.html` หน้าเว็บทั้งหมดอยู่ในไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย
- `images/` วางภาพหน้าจอที่นี่ แล้วแก้ช่อง `.shot` ใน `index.html` ให้ชี้มาที่ไฟล์

ก่อนเผยแพร่ ให้แก้ราคา จำนวนแขก และช่องทางติดต่อใน `index.html` ซึ่งยังเป็นค่าตัวอย่าง
